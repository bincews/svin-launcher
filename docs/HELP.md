# Справка Svin Launcher

## Первый запуск

В меню профиля справа сверху добавьте локальный профиль и укажите имя игрока.
Нажмите «Добавить экземпляр», выберите версию Minecraft и создайте экземпляр.
Для первого скачивания игры, библиотек и Java нужно подключение к Интернету.

Обычная кнопка «Запустить» загружает недостающие файлы. Автономный запуск
использует уже скачанные файлы: сначала подготовьте экземпляр при работающем
Интернете. Новые версии Minecraft появляются в каталоге версий автоматически.

<a id="Launcher-settings"></a>

## Настройки лаунчера

Откройте «Параметры», чтобы выбрать язык, оформление, папку экземпляров и Java.
Папка автоматически загружаемой Java относится к лаунчеру; не указывайте
вместо неё системную папку установки Java.

<a id="Java-settings"></a>
<a id="java-wizard"></a>

## Java и память

Используйте автоматический выбор подходящей Java либо укажите установленную
версию самостоятельно. Для Minecraft 1.21.10 подходит 64-разрядная Java 21.
Для небольшой модовой сборки на компьютере с 16 ГБ памяти начните с 4 ГБ
для игры. Остальную память оставьте Windows и другим приложениям.

<a id="Instance-Version"></a>

## Версия игры и моды

Выберите экземпляр и нажмите «Изменить». На странице версии устанавливаются
Fabric и другие загрузчики. Во вкладке модов добавляются совместимые с этой
версией игры и загрузчиком файлы. Для шейдеров нужен подходящий мод, например Iris.

Если не хватает библиотек или данных компонентов, повторите обычный запуск
при работающем Интернете. Не открывайте мир без необходимых ему модов.

<a id="instance-copy"></a>

## Копия экземпляра

Чтобы попробовать другую версию игры или набор модов, создайте копию экземпляра
через кнопку «Копировать». Перед изменением версии сохраните отдельную копию мира.

## Ошибки запуска

В меню «Справка» доступны журналы и ссылка для сообщения об ошибке.
Укажите версию Svin, версию игры, загрузчик модов и действия перед ошибкой.
Описание проекта и исходники: [bincews/svin-launcher](https://github.com/bincews/svin-launcher).
