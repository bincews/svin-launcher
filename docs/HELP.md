# Справка

<a id="Launcher-settings"></a>

## Профили и сборки

Локальный профиль добавляется через меню аккаунта справа сверху.
Новая сборка — через «Добавить экземпляр»; импорт ZIP — там же, во вкладке импорта.
Язык, оформление и каталоги находятся в «Параметрах».

Обычный запуск скачивает недостающие файлы. Автономный использует кеш.

<a id="Java-settings"></a>

## Java

В «Параметры → Java» доступен автоматический выбор или путь к своей Java.
Для Minecraft 1.21.10 используется Java 21 x64. Лимит памяти задаётся там же
либо отдельно для сборки: «Изменить → Настройки → Java».

<a id="Instance-Version"></a>

## Моды и шейдеры

«Изменить → Версия» — установка Fabric и других загрузчиков.
Вкладки «Моды» и «Шейдеры» — управление файлами выбранной сборки.
Для шейдеров нужен Iris или другой мод с их поддержкой.

## Скины Ely.by

В «Учётных записях» выбери локальный профиль и нажми «Загрузить скин Ely.by».
Аватар загрузится по нику и сохранится в лаунчере.

Для скинов в игре открой «Изменить → Моды → Скины Ely.by в Minecraft».
Svin откроет CustomSkinLoader в каталоге Modrinth с фильтрами выбранной сборки.
После установки мод подгружает скины Ely.by по игровым никам.

<a id="instance-copy"></a>

## Несколько вариантов сборки

В диалоге «Копировать» можно выбрать, какие данные попадут в новый экземпляр.

## Ошибки запуска

Журналы: «Справка → Просмотр журналов».
Сообщения об ошибках: [Issues](https://github.com/bincews/svin-launcher/issues).

«Справка → Проверить обновления Svin» показывает, доступна ли новая версия.
После нажатия «Обновить» лаунчер установит её в свою папку и перезапустится.
