# Справка Svin Launcher

## Как начать

1. Открой меню профиля справа сверху и добавь локальный профиль с нужным ником.
2. Нажми «Добавить экземпляр» и выбери версию Minecraft.
3. Выбери созданную сборку и нажми «Запустить».

Для первого запуска нужен интернет: лаунчер скачает игру, библиотеки и Java.
Потом можно запускать ту же сборку без сети. Новые версии Minecraft
появляются в списке при подключении к интернету.

<a id="Launcher-settings"></a>

## Настройки

Язык, оформление и папки меняются в «Параметрах».
Папку для скачиваемой Java лучше оставить по умолчанию. Если Java уже
установлена, укажи путь к ней в настройках Java, а не меняй папку загрузки.

## Java и память

Проще оставить автоматический выбор Java. Если выбираешь вручную,
для Minecraft 1.21.10 нужна 64-битная Java 21.

Для небольшой модовой сборки на компьютере с 16 ГБ памяти можно начать
с 4 ГБ для игры. Всю память компьютера выделять ей не стоит.

<a id="Instance-Version"></a>

## Моды и шейдеры

Выбери сборку и нажми «Изменить». На странице версии можно поставить Fabric
или другой загрузчик, а во вкладке модов — добавить сами моды.
Их версии должны подходить к игре и загрузчику.

Для шейдеров нужен мод с их поддержкой, например Iris. Сам шейдер-пак
добавляется во вкладке шейдеров.

Если запуск остановился из-за недостающих файлов, попробуй обычный запуск
с интернетом. Лаунчер сможет скачать то, чего не хватает.

<a id="instance-copy"></a>

## Перед изменением сборки

Кнопка «Копировать» создаёт отдельную копию сборки. На ней удобно пробовать
другую версию игры или новые моды. Мир перед такими изменениями лучше
сохранить отдельно.

## Если что-то сломалось

В «Справке» можно открыть журналы и перейти к сообщениям об ошибках.
Напиши, что нажимал перед сбоем, укажи версии игры и загрузчика и приложи ошибку
из журнала. Это поможет разобраться без долгой переписки.
