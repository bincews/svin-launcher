# Изменения относительно Prism

Основа: develop, коммит `899d2f3957215a09fe398a8a8cbb8a8a9c619968`.

## Запуск

- Локальные профили работают без Microsoft-аккаунта.
- Обычный запуск загружает файлы игры, автономный использует кеш.
- Исправлены пропуск загрузки библиотек и чтение метаданных после перезапуска.
- Неполные данные Fabric больше не приводят к запуску vanilla без модов.

## Интерфейс и сервисы

- Название Svin Launcher, иконка свиньи и собственная справка.
- Ссылки на проект Svin вместо сообществ и новостей Prism.
- Обновление официальными сборками Prism отключено.
- Встроенные ключи Microsoft, CurseForge и Imgur удалены.
- Каталог версий Minecraft и формат данных сохранены.

## Проверки

Windows x64: 24 набора CTest и 12 функций FileSystem
(25 проверок с параметрами и служебными шагами).
Тесты символических ссылок исключены.

Проверены обычный и автономный запуск Minecraft 1.21.10 с Fabric 0.19.5,
девятью модами и Complementary Reimagined; восстановление файлов и отказ
запуска при неполных данных компонентов.

Forge, NeoForge, Quilt и установка сборок из каталогов отдельно не проверены.
