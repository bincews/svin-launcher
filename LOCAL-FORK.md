# Изменения относительно Prism Launcher

Основа — ветка develop, коммит `899d2f3957215a09fe398a8a8cbb8a8a9c619968`.
История исходного проекта и лицензии сохранены.

## Профили и запуск

Локальный профиль можно добавить без Microsoft-аккаунта. При обычном запуске
он позволяет скачивать файлы игры, а при автономном используются только
ранее скачанные файлы. Проверки прав Microsoft-аккаунтов и режим Demo не менялись.

Исправлены три проблемы запуска:

- Локальный профиль пропускал загрузку библиотек и останавливался с Missing libraries.
- После перезапуска лаунчер не дожидался чтения метаданных из кеша.
- При отсутствии данных Fabric могла запускаться vanilla без модов.
  Теперь неполная сборка останавливается до запуска Java.

## Интерфейс и сервисы

Название Svin Launcher одинаково на русском и английском. Иконка — морда
свиньи из Minecraft. Справка ведёт в этот репозиторий; происхождение форка
указано в «О программе». Имена `prismlauncher.exe` и `prismlauncher.cfg`
сохранены, чтобы не переносить существующие настройки.

Официальный обновлятор Prism отключён. Его встроенные ключи Microsoft,
CurseForge и Imgur удалены. Свои ключи можно задать при сборке.
Каталог версий Minecraft остался прежним.

## Проверки

На Windows x64 прошли 24 набора CTest и отдельно 12 функций FileSystem
(25 проверок с параметрами и служебными шагами). Тесты символических ссылок
не запускались: они повторно запрашивают права администратора.

На отдельной копии проверены обычный и автономный запуск Minecraft 1.21.10,
Fabric 0.19.5, девять модов, миникарта и Complementary Reimagined.
Также проверены восстановление файлов при скачивании и отказ запуска
при неполных данных компонентов.

Forge, NeoForge, Quilt и установка сборок из каталогов отдельно не проверены.
Сборка в GitHub Actions ещё не запускалась.

Инструменты локальной сборки и команды — в [BUILDING.md](BUILDING.md).
