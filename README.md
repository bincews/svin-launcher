# Svin Launcher

Svin — лаунчер Minecraft для Windows на базе [Prism Launcher](https://github.com/PrismLauncher/PrismLauncher).
В нём можно играть с локальным профилем, держать несколько версий игры
и собирать отдельные наборы модов со своими настройками и мирами.

**[Скачать Windows x64](https://github.com/bincews/svin-launcher/releases/latest)**

## Возможности

- **Отдельные сборки.** У каждой своя версия Minecraft, загрузчик, моды,
  ресурспаки, шейдеры и настройки. Сборки можно копировать, импортировать и экспортировать.
- **Локальные профили.** Ник выбирается прямо в лаунчере, без предварительного
  добавления Microsoft-аккаунта. Svin автоматически подключает скины Ely.by
  по игровым никам в поддерживаемых версиях Minecraft.
- **Работа с модами.** Сохранены инструменты Prism для установки загрузчиков,
  управления модами и доступа к Modrinth. Каталог CurseForge требует своего API-ключа.
- **Java и память.** Автоматический выбор Java или свой путь, общие настройки
  памяти и отдельные параметры для каждой сборки.
- **Загрузка игры.** При обычном запуске Svin скачивает недостающие библиотеки
  и ресурсы. Автономный запуск использует подготовленные файлы.
- **Журналы запуска.** Логи игры и лаунчера доступны из интерфейса.

## Чем отличается от Prism

Основное изменение — независимые локальные профили. Они не требуют другого
аккаунта в списке и не переводят игру в Demo. При этом обычный запуск
сохраняет возможность скачивать файлы игры.

Также исправлены загрузка библиотек и чтение метаданных после перезапуска
лаунчера. Если данных Fabric не хватает, запуск останавливается с ошибкой,
а не открывает vanilla без модов.

У Svin своё название, иконка свиньи, справка и ссылки на этот репозиторий.
Встроенные ключи сервисов и обновление официальными сборками Prism отключены.
Подробности — в [списке изменений](LOCAL-FORK.md).

## Профили и сервисы

Локальный профиль подходит для одиночной игры и серверов, допускающих вход
без проверки Microsoft-аккаунта. На серверах с такой проверкой нужна
авторизованная учётная запись.

В готовой сборке не настроены вход Microsoft и каталог CurseForge:
для них нужны собственные ключи приложения. Параметры указаны в
[инструкции по сборке](BUILDING.md#ключи-сервисов). Modrinth доступен без этих ключей.

## Версии и обновления

Список версий Minecraft поступает из каталога Prism и обновляется независимо
от релизов Svin. Уже подготовленные сборки можно запускать автономно.

«Справка → Проверить обновления Svin» сравнивает установленную версию с релизами
на GitHub. После нажатия «Обновить» Svin заменит файлы лаунчера в той же папке
и запустится снова. Если обновлений нет, Svin показывает установленную версию.

## Текущая сборка

Сборка **r8** — переносная версия Windows x64. Исполняемый файл называется
`svinlauncher.exe`, настройки — `svinlauncher.cfg`. Настройки прежних версий переносятся автоматически.

На Windows 11 проверены обычный и автономный запуск Minecraft 1.21.10,
Fabric 0.19.5, набор из девяти модов и Complementary Reimagined.
Поддержка других загрузчиков сохранена из Prism; Forge, NeoForge и Quilt
отдельно не проверялись. Результаты тестов — в [LOCAL-FORK.md](LOCAL-FORK.md#проверки).
